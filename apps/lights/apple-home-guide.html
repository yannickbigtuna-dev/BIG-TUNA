Connect Apple Home

BIG TUNA Lights is a local HomeKit light. It controls the same desired state as the website; your ESP32 keeps polling the website exactly as it already does.

Pair once

  1. Put this iPhone and the BIG TUNA Windows server on the same normal home Wi-Fi/LAN. Do not use guest Wi-Fi or a VPN while pairing.
  2. Sign in to BIG TUNA as yannick and open Lights. The Apple Home panel shows the setup code while the bridge is unpaired.
  3. In Apple’s Home app, tap +, choose Add Accessory, then choose More options if the light is not suggested.
  4. Select BIG TUNA Lights, enter the code from the Lights page, and choose a room.
  5. Turn it on and off in Home. The relay follows on its normal ESP32 polling interval.

After pairing, normal BIG TUNA restarts and updates keep the Apple Home relationship. With a HomePod or Apple TV configured as a Home Hub, you can control it away from home.

If it does not appear

  • Confirm the phone and server are on the same LAN. Cloudflare/the public website cannot carry HomeKit discovery.
  • Allow inbound TCP 51826 on Windows’ Private firewall profile and local multicast DNS (UDP 5353). Do not open either to the public Internet.
  • Restart the BIG TUNA server after installing the new dependency, wait about 30 seconds, then try More options again.

Do not delete data/lights/homekit/: it contains the secure HomeKit pairing identity and deleting it requires a new pairing.
